Cluedle

One page of plain HTML, CSS, and JavaScript. Cases are data, rules are tested, the board is the screen, and progress lives in the browser.

How it fits togetherThe pieces

The app shell, src/main.js, is the wiring between these: it hands board actions to the rules, then saves progress right after every rule call.

The core journey through the systemWho does what, in order

main.js asks daily.js for today's date and case, and progress.js for today's saved progress.main.jsdaily.jsprogress.js

caseFile.js shows the cover. Open the file moves on.caseFile.js

If cluedle:seenHowTo isn't set, howToPlay.js shows the overlay and sets it on close.howToPlay.js

board.js lays out the pins from the case data and redraws saved stamps, clues, strings, and cipher state.board.jscase-N.js

string.js ties or removes a string between two pin ids and saves it. Rules never read it.string.js

Clicking the scrawl opens decoder.js. Decode asks cipher.js: right reveals the message with blots for earlier misses; wrong adds a blot stage.decoder.jscipher.js

stamps.js collects a GUILTY suspect and motive. rules.js checks both halves, uses a guess, unlocks a clue or ends the case. Stamps recolor blue or red.stamps.jsrules.js

stamps.js collects a LIAR statement and a picked truth. rules.js records the one shot.stamps.jsrules.js

On closed or cold, rank.js scores a solved run and ending.js shows the ending.rank.jsending.js

share.js builds the case-file text; ending.js copies it or shows it to copy by hand.share.jsending.js

Same day, progress says closed or cold, so main.js shows the finished board, ending, and countdown from daily.js.main.jsdaily.js

StackSmall on purpose

  • HTML, CSS, JavaScript ES modules: no framework, no build. Tradeoff accepted: run npx serve . instead of double-clicking.
  • SVG for string and the decoder wheel; pointer events for mouse and touch.
  • localStorage for progress; Clipboard API for the share card.
  • node --test for the rules: nothing to install.
  • Google Fonts: Special Elite (typewriter), Playfair Display (headlines), with Courier New and Georgia fallbacks.

Run it

npx serve .          # then open the address it prints
npm test             # rules and case checks
?case=2&fresh        # demo aid: load case 2, ignore saved progress

ComponentsWhere each PRD behavior lives

Game rules · rules.js prd › Accusing, Clues, LIAR, Ending
  • accuse(state, suspectId, motiveId) → both halves right or wrong, uses a guess, unlocks the next clue or ends the case on a solve or the 5th miss.
  • flagLiar(state, statementId, truthIndex) → once per case, never touches guesses.
  • Rejects any action after the case ends.
Cipher · cipher.js prd › Finding and Cracking the Cipher
  • Letter shift over A–Z. The case stores plaintext and shift; the scrambled text is generated, so it can't drift.
  • Three tries, then locked. The wheel only changes a number; it never decodes.
  • Blots: 0% → ~30% → ~60% of letters, chosen by a seeded shuffle of the case id so blots only add up. keepWords never blot.
Daily case · daily.js prd › Daily Case
  • Local date → case number (days since 2026-10-24, plus one) → case (number − 1, mod 3).
  • Countdown to local midnight. ?case=N overrides for demos.
Rank · rank.js prd › Detective Rank
  • Guesses left 0–4, cipher 3/2/1/0, liar 3 → 0–10 points.
  • Amateur Sleuth 0–1 · Private Eye 2–3 · Hard-Boiled Investigator 4–5 · Seasoned Detective 6–7 · Basically Sherlock 8–10.
  • One table at the top of the file, easy to tune.
Share card · share.js prd › Share Card
  • Case-file text: CLOSED in N/5 or GONE COLD, 🔓/🔒, 🎭, rank, the case's noir line.
  • No names, no orange, yellow, or green emoji. Tested.
Progress · progress.js prd › States and Boundaries
  • cluedle:progress:<date> saved after every rule call; old days deleted.
  • Blocked storage never breaks play.
Screens · src/ui/ prd › Screens and Layout
  • caseFile.js cover · howToPlay.js overlay · board.js pins with stable ids · stamps.js pick up, stamp, confirm, recolor · string.js SVG curves between pins · decoder.js wheel, Decode, unscramble animation · ending.js ending, rank, copy, countdown.

Look and feel, buildableNoir under one lamp

  • A corkboard under a desk lamp: a warm pool of light in the center, falling off into dark edges.
  • CSS variables: night #13111c, paper #efe9dd, desaturated violet-brown cork, red #b3263a, blue #2f5aa8, purple #6b3fa0. No orange, yellow, or green, including focus rings and emoji.
  • Special Elite for statements and the case file; Playfair Display for headlines; a plain serif for the story.
  • Stamps with uneven ink and a quick thump; terse hard-boiled copy.

Lead the demo with the bold rows. The first build step is a static look test of case 1, so you can judge the noir look in the browser before any rules are wired up.

Simplified, on purposeWhat we're not building yet

  • One cipher and exactly one liar per case: keeps scoring fair and simple.
  • Static string curves, no physics.
  • Three cases rotating by date; more cases are just more files.
  • CSS textures, no image assets.
  • No browser-automation suite: rules are tested; screens are checked by playing each build step.

Still open, fine for the build

  • How hidden the scrawl should be, tuned while playtesting.
  • Rank point values and bands, tuned while playtesting.
